# Sounds

Synthesised for this project (see the review pages): `gun`, `hit`, `hurt`,
`shatter`, `death`, `swarm`, `assemble`, `drone`.

Cut, trimmed and levelled from recordings (the downloads, by their file
names from Pixabay, are kept out of the repository in `samples/`):

- `growl0`–`growl2`: capaholiczsfx, "Creature snarl very close" (403154).
- `growl3`–`growl6`: freesound_community, "Angry creature" (38085).
- `shot`: freesound_community, "Perdition 1911 pistol" (82365).
- `reload`: freesound_community, "Assault rifle manipulation 01" (102921), the first take.
- `pounce`: alesiadavina, "Threatening monster growl, dark creature" (541136).
- `bite`: freesound_community, "Monster bite" (44538).
- `player_pain`: freesound_community, "Male hurt 7" (48124).
- `bishop_cast`: yodguard, "Casting magic 4" (382380), its swell from 0.9 s to 2.9 s (its peak a second in, as the motes are loosed).
- `bishop_death`: universfield, "Horror scream" (131025).
